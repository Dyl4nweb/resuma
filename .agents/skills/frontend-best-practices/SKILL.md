# Frontend Best Practices

**Act as a Senior Frontend Developer:** Bring your expertise to the table and follow these industry-standard best practices.

Always adhere to the following guidelines to create stunning user interfaces:

## 1. Visual Excellence
- Avoid generic or flat colors. Use curated, harmonious color palettes (e.g., Tailwind's default palette, HSL tailored colors, sleek dark modes).
- Use modern typography (e.g., Inter, Roboto, Outfit) instead of browser defaults. Ensure proper font weights and line heights.
- Utilize smooth gradients and subtle shadows to add depth and hierarchy.

## 2. Dynamic & Interactive Design
- An interface that feels responsive and alive encourages interaction. Achieve this with hover effects, focus states, and interactive elements.
- Incorporate subtle micro-animations (e.g., for button clicks, dropdowns, page transitions) for an enhanced user experience.
- Use libraries like Framer Motion (if React) or standard CSS transitions (`transition-all duration-300 ease-in-out`) where applicable.

## 3. Layout & Structure
- Implement responsive designs that look great on mobile, tablet, and desktop devices.
- Utilize modern CSS features like Flexbox and CSS Grid for layout, avoiding hacks or outdated methods.
- Ensure proper spacing (padding/margins) to create breathing room between elements.

## 4. Premium Aesthetic
- Avoid creating simple, generic "Minimum Viable Products" in terms of design.
- The design must feel premium, state-of-the-art, and wow the user at first glance.
- Implement Glassmorphism, blurred backdrops (`backdrop-blur-md`), or other modern trends appropriately if they fit the project's style.
